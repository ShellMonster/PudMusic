## 提交信息

**出处**：`AGENTS.md` §8《提交信息》

照 `git log` 现在的写法：**中文一句话 + 票号**，例如

```
分集抽屉 (#116)
修网格虚拟滚动的飘红测试 (#121)
```

（`feat:` / `fix:` 那套前缀只在最早的十几个脚手架提交里出现过，后来不再用了。）

**分支和 PR 由工作板管，agent 不要自己 push 或往别的分支合。**

⚠️ **不要自己写 `Closes #N`**，连写在反引号里也不行——板子看到正文里已经有这个字符串，
就**不再加它自己那行**；而 GitHub **不认代码块里的关闭关键字**——两头落空，票就一直
开着（2026-10-24 就这么漏过一张，#244）。**只写「对应 issue #216」。**

**什么时候用得上**：你写完一个改动、要写提交信息的时候。

## 注释的纪律

**出处**：`AGENTS.md` §7《注释说谎比没有注释更坏》

**注释说谎比没有注释更坏。**

审计查出过至少**五条**注释与代码不符——写着「还没接（issue #29）」，而 #29 早就完成了。

**注释里不要写「还没做」，写你当时在做什么。**「还没做」这个状态会过期，而过期的注释会
让下一个人以为那个功能不做，或者照着一条已经不成立的注释去改代码。

改动涉及某个功能的现状时，**顺手把相关注释改对**。

**什么时候用得上**：你在改一个功能，顺手看看周围的注释有没有说谎；或者你在照着一条注释
改代码，发现它和代码对不上。

## 仓库里哪些东西不是文档

**出处**：`AGENTS.md` §9《技能文档与两份不在仓库里的东西》

这一节记的是「**别去找**」——省下的是时间，不是知识。

| 东西 | 在哪 | 为什么找不到 |
|---|---|---|
| **术语表 / 决策记录** | `GLOSSARY.md`、`docs/adr/` **目前不存在** | 这个仓库还没有统一术语和决策记录。别去找、**别因为找不到就停下来**——`docs/agents/domain.md` 说得很清楚：这两个文件在术语或决策真的被敲定之前不存在，届时才由 `/domain-modeling` 那条路懒创建。要造新的领域概念时，顺手留意有没有一个词已经在这个仓库里被用成了别的意思。 |
| **规格与实施计划** | `docs/research/SPEC.md`、`docs/research/PLAN.md` | 是维护者**本机**的工作文档，**不进版本库**——`.gitignore` 第 6 行那条 `docs/research/` 兜着它们。在仓库里、在别的克隆里、在 worktree 里都找不到它们是正常的。⚠️ 那条规则**只认 `docs/research/` 这一个路径**，所以别把 SPEC.md / PLAN.md 挪到别处再提交——换个位置就不再被忽略了，`git add` 会照常把它列成待提交。 |
| **回归证据清单** | `internal/evidence` | 它是**代码**，不是文档。 |
| **票与规格** | GitHub Issues（`gh` CLI） | 见 `docs/agents/issue-tracker.md`。 |

**什么时候用得上**：你在找一个「应该有」的文档，或者你要在仓库里造一个新的领域概念。

## 文件怎么组织

**出处**：`AGENTS.md` §11《文件怎么组织》

仓库里从前没有「一个文件该多大」的规矩，于是 agent 只会往上加：`internal/ui/shell.go`
在 #357 那次重设计之后的 8 个提交里从 **1697 行涨到 1798 行**；
`internal/app/queue.go` 1866 行、`internal/evidence/evidence.go` 3502 行。

> 下面的行数是 **2026-10-25 量的一次快照**。这一节看的是**职责和耦合**，不是这个数
> ——数会过期，判断不会。

### 什么时候该拆

**一个文件超过 ~1200 行、并且能按职责说清两三块的时候。**

- 「**能按职责说清**」是前提：**说得清**才拆得动；说不清就是**一团**，拆了只是把一团
  分成几团，反而更难找。
- **行数只是信号，不是判据**——见下面「什么时候别拆」。

`internal/ui/shell.go` **从前**是能说清的那种：它**曾经**同时装着**窗口生命周期**
（`Attach`、`Close`、`bindMedia`、`Run`）、**画法**（`View`、`viewMain`、
`viewFolderDialogs`）、**崩溃兜底**（`Guard`、`onPanicAt`、`newCrashInfo`、`viewCrash`）
和**挂载**（`mountSearchHistory`、`mountShortcuts`）四块——四块之间没有互相依赖的顺序，
搬开就是四个文件。

**票 #404 已经拆完了**（2026-10-25）：`shell.go` 现在只剩 `Shell` 结构体和装配它的那几段，
四块各自搬到了按职责命名的文件里。

### 怎么拆：优先「纯搬文件」

**把方法搬到按职责命名的文件里，字段和引用一处都不改。**

```
internal/ui/shell.go  →  shell_window.go   窗口生命周期
                        shell_view.go     画法
                        shell_crash.go    崩溃兜底
                        shell_mount.go    挂载
```

- **Go 编译器保证行为不变 → 风险几乎为零**：搬完 `go build` 绿、测试绿，就是搬对了。
  同一包内搬方法不需要改任何调用点。
- ⚠️ **不要为了「struct 好看」把字段拆成子结构**：那要改**所有**引用点。队列抽屉那一块
  的状态（`drawerOpen`、`queueScroll`、`queueRowKeys`……）散在 `internal/ui` 的 **6 个
  文件**里、**85 处**引用；把它挪进子结构就是这 85 处都要跟着改。收益是「结构体小
  一点」，代价是**每次改那块状态都要跨两个 struct**——**不值**。

### 什么时候别拆

- **一张表的文件**：`internal/evidence/evidence.go` 里三千多行是
  `var Items = []Item{` 那**一张台账**——它是**台账不是逻辑**（回归证据是**代码**，不是
  文档）。**行多不代表耦合多**，拆了反而破坏「一张台账」这个概念：读者要的是「这一条
  证据在哪儿」，拆成三个文件就得先知道它归哪一组。
- **正在被连续改的那一块**：等这波改完再动（比如队列那一摊——`internal/app/queue.go` 和
  队列抽屉正是最近几票在改的地方；这波改到一半拆文件，两拨改动会撞在一起）。
- **生成物**：`go generate` 造出来的那些（图标和第三方许可清单）——改了图案却忘了重新
  生成，仓库里躺着的是旧文件，而**没有任何一处会报错**。

**什么时候用得上**：你在决定要不要拆一个文件；或者你接手一个「这个文件好大」的活。

## 工作板与 worktree

**出处**：`AGENTS.md` §1 里 `-trimpath` 那段的理由（+ 板子的规矩）

这一节记的是**协作侧**的几件事实，省得下一个人重新推。

### 规矩

- 每个 agent 在**自己的 worktree** 里干活（板子建的），分支是 `work/<票号>`。
- **分支和 PR 由工作板管**：agent 提交到自己的分支，**不要自己 push、合并或切分支**。
  板子会跑验收命令并开 PR。
- **一个 agent 的临时文件**放在它自己的 `$TMPDIR` 下的专属目录里，**不要**散在 `/tmp`
  或家目录里——板子会在这一票结束时把它连同还活着的进程一起收掉。
- **收尾**：把自己工作区里那个 gopls 停掉，否则板子清不掉这个工作区。完整做法见
  `docs/agents/cleanup.md`。

### 为什么 `-trimpath` 是全板一致的

验收命令里的 `-trimpath` 不是洁癖：**本板子上每个 agent 有自己的 worktree**，源码所在的
**绝对路径每个 worktree 都不同**，而 Go 的编译缓存 key 里带着「包所在目录」——路径一变，
同一份源码在另一个 worktree 就是**另一个 action**。

实测：内容只差 1 个文件的两个副本，第二个要重编 **38** 个包；每多一个 worktree 缓存多占
**41 MB**。`-trimpath` 把产物里的源码路径换成 **module 路径 + 相对路径**，路径不再进 key，
缓存就能跨 worktree 共享（实测：38 → **4** 个包，41 MB → **0.85 MB**）。

⚠️ **半开半开会让缓存翻倍到 518 MB**，比现状更糟——所以**所有 agent 必须一致**。改那条
命令的票必须**在同一个提交里**改完 `AGENTS.md` + `DESIGN.md` + 全部 open 票面；**板子
自己的 check 命令也是一处**（`herdr-projects set check.command '…' --repo Biu_MyGo`）。

**什么时候用得上**：你在改验收命令、或者你在查「为什么编译缓存越滚越大」。
